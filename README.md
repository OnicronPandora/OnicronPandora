## 🚀 Featured Projects

### 🤖 [Mika-sama](https://github.com/OnicronPandora/mika_sama_v1)
> *An AI chatbot that can chat with you all day long.*

A local-first AI companion with long-term memory and a voice.

| Feature | How it works |
|---|---|
| 💬 **Conversational core** | Local LLMs served through **Ollama**, with streaming replies and model warm-up |
| 🧠 **Memory & state** | Long-term memory in **PostgreSQL + pgvector**; session state in **Redis** |
| 🎙️ **Voice** | Speech-to-text with **Whisper** + VAD, then text-to-speech for replies |
| 🛡️ **Output filter** | A post-processing layer that cleans and shapes model output before it reaches the user |
| 🖥️ **Frontend** | **React** UI talking to a **FastAPI** server |

`Python` · `FastAPI` · `Ollama` · `PostgreSQL` · `Redis` · `React`
